## About

I'm a full-stack engineer who builds web applications and backend systems with TypeScript, React, Next.js, and Node.js. I care about clean, maintainable code and about designing systems that hold up under real-world constraints: sensible architecture, secure authentication, and performance that doesn't fall over under load.

Alongside full-stack work, I focus on applied AI engineering: retrieval-augmented generation, stateful agent workflows, and the evaluation needed to make AI features dependable rather than just impressive in a demo.

**Open to freelance, contract, and full-time opportunities.**

## Engineering Focus

**Full-stack and backend**
- Designing scalable full-stack architectures with clear boundaries between client, API, and data layers
- Building production-ready REST APIs and integrating external services
- Performance optimization and caching
- Secure authentication and authorization

**Applied AI**
- Retrieval-augmented generation (RAG) pipelines and retrieval-based applications
- Stateful, multi-step agent workflows with LangChain and LangGraph
- Connecting models to tools and external services through the Model Context Protocol (MCP)
- Human-in-the-loop approval steps for AI actions that need oversight
- Evaluating model outputs and improving reliability
